# 站務工作助手：手機 GitHub Pages PWA版 v4.6.2

這個版本供手機透過 GitHub Pages 安裝使用。手機採單欄及底部分頁操作；程式、PDF與Excel解析套件及介面資源都包含在本資料夾內，不使用外部CDN、雲端資料庫、分析服務或後端API。公司電腦請改用另外提供的電腦版HTML，不要直接雙擊本資料夾的 `index.html`。

## 資料會放在哪裡

- 匯入的 PDF、SOP、通告、常用程序、同義詞及其他資料，保存在該手機瀏覽器的 IndexedDB。
- 網頁伺服器只提供本資料夾內的靜態程式檔；使用者匯入的公司資料不會由程式上傳。
- 不同手機、不同瀏覽器、一般／無痕模式的資料彼此獨立。
- 電腦與手機使用相同網址，但資料不會自動同步；如需相同內容，請用 JSON 備份手動移轉。

## 電腦移轉到手機

1. 在電腦版「設定 → 資料與儲存」選擇「匯出常用程序與通告」。
2. 將產生的 JSON 移轉檔傳到 iPhone。
3. 在手機版同一位置選擇「匯入常用程序與通告」。
4. 先確認預覽中的常用程序、SOP 識別、通告 PDF、標註、關聯及無法配對項目，再選擇「合併匯入」或「取代移轉資料」。

輕量移轉不包含 SOP PDF 或解析正文；手機會用 SOP 名稱、PDF 檔名及內容指紋配對既有文件。移轉內容包含常用程序、螢光筆與底線標註、通告資料及 PDF，以及通告與 SOP／常用程序的關聯。運量與其他設定不會被取代。「完整資料備份」仍僅用於同一裝置復原。

## 運量與大型活動

- 年度運量 Excel 使用 `01`～`12` 分頁，必要欄位為「車站名稱」與「平均日運量」。
- 只匯入 BR、R、G、O、BL；Y 環狀線自動排除，未知代號列入警告。
- 大型活動 Excel 必填「活動名稱、開始日期、影響車站代號」，工作表可命名為「大型活動」。
- 多個影響車站代號可用頓號、逗號、分號或空格分隔；活動資料僅保存在本機。

## iPhone / iPad 安裝

1. 將整個資料夾原樣放在公司內部或受控的 HTTPS 靜態網站。PWA 不能直接從 ZIP 或 `file://` 安裝。
2. 用 Safari 開啟 `index.html` 的網址，等首頁完整顯示。
3. 點 Safari 的「分享」→「加入主畫面」→「新增」。
4. 從主畫面的「站務助手」開啟，匯入 PDF 或 JSON 備份。
5. 安裝完成後先開啟一次，再切到飛航模式測試搜尋、PDF 顯示及重新開啟。

Android 可用 Chrome 開啟相同 HTTPS 網址，再選「安裝應用程式」或「加到主畫面」。

## 電腦測試

在本資料夾執行：

```bash
python3 -m http.server 8080
```

再開啟 `http://localhost:8080/`。`localhost` 可供開發測試；手機正式安裝仍應使用 HTTPS。

## 備份與換機

請定期從底部「設定」→「資料與儲存」匯出 JSON 備份，另存到公司允許的安全位置。更換手機時，在新手機安裝本 App 後再匯入 JSON；PDF 若未包含於既有備份流程，請重新匯入原始 PDF。

刪除主畫面 App、清除 Safari 網站資料、使用系統清理工具或重設手機，都可能清除本機資料。程式不會在雲端保留副本。

## 更新程式

替換靜態網站上的檔案後，修改 `sw.js` 內 `CACHE_NAME` 的版本（例如 `v1` 改為 `v2`）。手機連上內部網站並開啟 App 一次，更新完成後即可再次離線使用。更新程式通常不會刪除 IndexedDB，但更新前仍建議先匯出 JSON。

## 管理建議

- 網站設為僅公司網路、VPN 或受控裝置可連線。
- HTTPS 主機不要記錄 URL 參數或加入第三方追蹤碼。
- 不要自行加入會把 PDF 或搜尋文字送到外部的 AI、OCR、字型或分析服務。
- 若日後加入離線 AI，模型檔也應放在相同受控站點並在裝置本機推論。
